# HR Employee Attrition Dashboard (Power BI)

## Dashboard Preview
<img src="HR%20Dashboard.png" width="900"/>


## Overview

This project analyzes employee attrition patterns using Power BI. The goal is to identify key drivers of employee turnover and provide actionable insights for HR decision-making.


## Key Metrics

* Total Employees: 1470
* Attrition Count: 237
* Attrition Rate: 16.1%
* Active Employees: 1233
* Average Salary: $6.5K
* Average Tenure: 7.01 years
* Average Age: 36.92

## Key Insights

* Higher attrition observed in the **Sales department**
* Employees with **lower tenure (early years)** show higher attrition
* **Overtime employees** have higher attrition rates
* Lower **job satisfaction and work-life balance** are strong drivers
* Employees with **longer commute distance** tend to leave more

## Dashboard Features

* Department-wise attrition analysis
* Age group and gender-based segmentation
* Job role-level insights
* Business travel impact analysis
* Education field and demographic breakdown
* Interactive filters for deep analysis

## Tools Used

* Power BI
* DAX (Data Analysis Expressions)
* Power Query

## Business Value

This dashboard helps HR teams:

* Identify high-risk employee segments
* Improve retention strategies
* Make data-driven workforce decisions
